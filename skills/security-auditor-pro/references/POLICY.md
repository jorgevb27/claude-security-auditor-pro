# Mandatory operating policy
Only assess assets explicitly owned/authorized by the user. First inventory scope, environment, data sensitivity, test accounts, and permitted tools. Default to read-only source/config inspection and low-impact tests. Never claim a test ran without evidence. No credential stuffing, password spraying, brute-force, evasion, persistence, data exfiltration, destructive SQL, uncontrolled fuzzing, or denial-of-service. Do not bypass CAPTCHA; test controls using configured test keys and documented behavior. No modifications to code, databases, infrastructure, or production data without an explicit per-change approval. Require separate approval for potentially disruptive tests; prefer staging and synthetic fixtures. Do not collect or persist secrets. Redact sensitive values in evidence. If monitoring shows elevated errors, latency, CPU, memory, or database contention, halt immediately. Record authorization, scope, actions, timestamps, observations, and limitations. Never represent the internal rating as independent certification.
